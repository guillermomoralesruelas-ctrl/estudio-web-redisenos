# Cacao Spa Tulum: plan de rediseño (método 1.2)

**Sitio original:** https://www.cacaospatulum.com/
**Materia prima:** 8 fotos descargadas de irp.cdn-website.com, textos en `investigacion/crudo.json`.
**Rubro:** Spa. **Ciudad:** Tulum, Quintana Roo.

## Dirección visual

| Token | Color | Uso |
|---|---|---|
| fondo | #faf7f2 (ivory) | página entera |
| acento | #5a6d41 (verde salvia) | CTAs, highlights |
| texto | #1c1109 (casi negro cacao) | encabezados |
| texto secundario | stone-600 | párrafos |

**Tipografía:** Cormorant Garamond (serif, evoca spa natural) + Inter (body)

## Elemento memorable

**"¿Qué ritual necesitas hoy?"** — cuatro tabs: Masajes / Faciales orgánicos / Faciales clínicos / Paquetes. Cada tab muestra la foto del servicio, descripción breve y CTA de WhatsApp específico. Refleja el proceso de reserva del sitio original ("Step 1: Choose a massage") pero de forma visual e integrada.

**Revisión contra lo genérico:**
- No son 4 tarjetas idénticas (las tabs ocultan el contenido inactivo)
- No hay numeración 01/02 ni separadores de puntos
- Sin animaciones de scroll

## Estructura

1. Hero — foto interior, H1, descripción, CTA WhatsApp + CTA Maps
2. ¿Qué ritual necesitas hoy? (elemento memorable)
3. Nuestros espacios — 3 fotos de salas en cuadrícula
4. Horario y ubicación
5. Footer + barra fija móvil
